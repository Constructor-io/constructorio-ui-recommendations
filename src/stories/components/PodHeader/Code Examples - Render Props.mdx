# `PodHeader` - Code Examples with Render Props

Use the Render Props pattern to customzie the rendering logic of the `PodHeader` component.

## Using Render Props

<Canvas of={PodHeaderStories.RenderPropsPattern} />

```jsx
import { PodHeader } from '@constructor-io/constructorio-ui-recommendations';

export default function MyComponent() {
  return (
    <PodHeader podHeader='Featured Collection' podSubheader='Hand-picked by our team'>
      {({ podHeader, podSubheader }) => (
        <header className='render-props-showcase'>
          <div className='showcase-content'>
            <h2 className='showcase-title'>{podHeader}</h2>
            {podSubheader && <span className='showcase-subtitle'>{podSubheader}</span>}
          </div>
          <button className='view-all-btn'>View All</button>
        </header>
      )}
    </PodHeader>
  );
}
```
