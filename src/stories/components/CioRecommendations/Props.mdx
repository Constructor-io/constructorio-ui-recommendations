# Props

<ArgTypes />

## CioClientOptions

Configuration options for the Constructor.io client.

For the full list of client options, do refer to https://constructor-io.github.io/constructorio-client-javascript/ConstructorIO.html#setClientOptions

## RecommendationsParameters

Additional parameters that can be passed to the Constructor.io Recommendations API.

| Property      | Type                 | Description                               |
| ------------- | -------------------- | ----------------------------------------- |
| numResults    | `number`             | Number of results to return               |
| section       | `string`             | Section to filter results by              |
| itemIds       | `string | string[]`  | Item ID(s) for item-based recommendations |
| filters       | `object`             | Additional filters to apply               |
| hiddenFields  | `string[]`           | Fields to hide from the response          |
| variationsMap | `VariationsMap`      | Map of variations configuration           |

For the full list of request parameters, do refer to https://constructor-io.github.io/constructorio-client-javascript/module-recommendations.html#~getRecommendations

## ItemFieldGetters

ItemFieldGetters maps the fields sent in the catalog feeds to the fields the library expects for rendering

| Property         | Type                                                 | Description                                                                                                                      |
| ---------------- | ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| getPrice         | `(item: Item &#124; Variation) => number \| undefined`   | Maps the price field from the API Response in `item.data`. Defaults to `item.data.price`                                         |
| getSalePrice     | `(item: Item \| Variation) => number \| undefined`   | Maps the sale price from the API Response in `item.data`. Defaults to `item.data.sale_price`                                     |
| getRolloverImage | `(item: Item \| Variation) => string \| undefined`   | Maps the rollover/hover image URL field from the API Response in `item.data`. Defaults to `item.data.rollover_image`             |
| getSwatchPreview | `(variation: Variation) => string \| undefined`      | Maps the swatch preview from the API Response in `variations.data`. Defaults to `variation.data.swatch_preview`                  |
| getSwatches      | `(item: Item, options) => SwatchItem[] \| undefined` | Maps the swatches object from the API Response from `item.variations`. Builds a SwatchItem array by iterating through variations |
