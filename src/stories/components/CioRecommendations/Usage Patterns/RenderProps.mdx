# Render Props

This document describes the **render props API** exposed by CioRecommendations. For a full explanation of how render props work, see the [Usage Patterns Reference](./?path=/docs/basic-concepts-usage-patterns--docs).

Render props allow you to fully control how the component is rendered by passing a function that receives the component's internal state and helpers, while the component continues to manage behavior and state.

Use this reference to understand **which render props are available**, their types, and when to use them.

---

## Usage

The CioRecommendations component accepts a render function as its `children` prop.

```tsx
<CioRecommendations apiKey="YOUR_API_KEY" podId="YOUR_POD_ID">
  {(props) => (
    <div>
      {/* Custom rendering using render props */}
    </div>
  )}
</CioRecommendations>
```

## Available Render Props

Accessible to children of the CioRecommendations component via render props

| Property            | Type                                  | Description                          |
| ------------------- | ------------------------------------- | ------------------------------------ |
| items               | `Item[]`                              | Array of recommendation items        |
| podId               | `string`                              | The pod ID being displayed           |
| podSubheader        | `string \| undefined`                 | Optional subheader text              |
| cioClient           | `ConstructorIOClient \| null`         | Constructor.io client instance       |
| cioClientOptions    | `CioClientOptions`                    | Configuration options for the client |
| setCioClientOptions | `(options: CioClientOptions) => void` | Function to update client options    |
| parameters          | `RecommendationsParameters`           | API request parameters               |
| itemFieldGetters    | `ItemFieldGetters`                    | Functions to extract item data       |

## Example

<Canvas of={CioRecommendationsStories.RenderProps} />

```jsx
import CioRecommendations from '@constructor-io/constructorio-ui-recommendations';

export default function MyComponent() {
  return (
    <CioRecommendations apiKey="YOUR_API_KEY" podId="YOUR_POD_ID">
      {({ items, podId }) => (
        <div className='render-props'>
          <div className='header'>
            <h2 className='title'>Featured Recommendations</h2>
            <p className='subtitle'>Personalized picks for you from {podId}</p>
          </div>
          <div className='grid'>
            {items.slice(0, 6).map((item) => (
              <div key={item.id} className='card'>
                <img src={item.imageUrl} alt={item.name} />
                <h3>{item.name}</h3>
                {item.price && <div className='price'>${item.price}</div>}
              </div>
            ))}
          </div>
        </div>
      )}
    </CioRecommendations>
  );
}
```
