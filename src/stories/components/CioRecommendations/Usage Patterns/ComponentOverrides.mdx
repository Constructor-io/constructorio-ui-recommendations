# Component Overrides

This document describes the **component overrides API** exposed by CioRecommendations. For a full explanation of how component overrides work, see the [Usage Patterns Reference](./?path=/docs/basic-concepts-usage-patterns--docs).

The component overrides pattern allows you to customize specific parts of a component's rendering by providing **custom content** or **render functions**. This pattern lets you change the markup or behavior of subcomponents without rewriting or wrapping the entire component.

Use this reference to understand **which keys can be overridden**, their types, and their purpose.

---

## Usage

CioRecommendations supports overrides via the `componentOverrides` prop.

```tsx
<CioRecommendations
  apiKey="YOUR_API_KEY"
  podId="YOUR_POD_ID"
  componentOverrides={{
    podHeader: {
      reactNode: ({ podHeader, podSubheader }) => <CustomHeader title={podHeader} />,
    },
  }}
/>
```

## Available Override Keys

| Key       | Type                                                     | Description                                                                                          |
| --------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| reactNode | `ReactNode \| (RecommendationsRenderProps) => ReactNode` | Override the entire CioRecommendations render                                                        |
| podHeader | `PodHeaderOverrides`                                     | Override the [PodHeader](./?path=/docs/components-podheader-usage-patterns-component-overrides--docs) component |
| carousel  | `CarouselOverrides`                                      | Override the Carousel component from constructorio-ui-components                                     |

## Override the Entire Component

Replace the entire CioRecommendations render with a custom implementation while still benefiting from the component's data fetching.

<Canvas of={CioRecommendationsStories.OverrideEntireComponent} />

```jsx
import CioRecommendations from '@constructor-io/constructorio-ui-recommendations';

function App() {
  return (
    <CioRecommendations
      apiKey="YOUR_API_KEY"
      podId="YOUR_POD_ID"
      componentOverrides={{
        reactNode: ({ items, podId }) => (
          <div className="custom-recommendations">
            <h2>Products from {podId}</h2>
            <ul>
              {items.map((item) => (
                <li key={item.id}>{item.name}</li>
              ))}
            </ul>
          </div>
        ),
      }}
    />
  );
}
```
### CSS

```css

  padding: 24px;
  background: linear-gradient(135deg, #6366f1 0%, #4f46e5 100%);
  border-radius: 16px;
  color: white;
}

  margin: 0 0 16px;
  font-size: 24px;
  font-weight: 700;
}

.custom-recommendations ul {
  list-style: none;
  padding: 0;
  margin: 0;
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 8px;
}

.custom-recommendations li {
  background: rgba(255, 255, 255, 0.15);

  font-size: 14px;
  transition: background 0.2s;
}

.custom-recommendations li:hover {
  background: rgba(255, 255, 255, 0.25);
}
```

## Override the Carousel

Customize the carousel component while keeping the pod header intact.

<Canvas of={CioRecommendationsStories.OverrideCarousel} />

```jsx
import CioRecommendations from '@constructor-io/constructorio-ui-recommendations';

function App() {
  return (
    <CioRecommendations
      apiKey="YOUR_API_KEY"
      podId="YOUR_POD_ID"
      componentOverrides={{
        carousel: {
          reactNode: ({ items }) => (
            <div className="custom-grid">
              {items.map((item) => (
                <div key={item.id} className="grid-item">
                  <img src={item.imageUrl} alt={item.name} />
                  <p>{item.name}</p>
                </div>
              ))}
            </div>
          ),
        },
      }}
    />
  );
}
```

```css
.custom-grid .grid-item {
```

## Override the Pod Header

Customize the recommendation pod header while keeping the carousel intact.

<Canvas of={CioRecommendationsStories.OverridePodHeader} />

```jsx
import CioRecommendations from '@constructor-io/constructorio-ui-recommendations';

function App() {
  return (
    <CioRecommendations
      apiKey="YOUR_API_KEY"
      podId="YOUR_POD_ID"
      podSubheader="Curated picks for you"
      componentOverrides={{
        podHeader: {
          reactNode: ({ podHeader, podSubheader }) => (
            <div className="custom-header">
              <span className="badge">Featured</span>
              <h2>{podHeader}</h2>
              {podSubheader && <p>{podSubheader}</p>}
            </div>
          ),
        },
      }}
    />
  );
}
```

### CSS

```css

  border-radius: 12px;
  margin-bottom: 16px;
}

.custom-header .badge {
  background: white;
  color: #d97706;
  padding: 4px 12px;
  border-radius: 20px;
  font-size: 12px;
  font-weight: 700;
  text-transform: uppercase;
}

.custom-header h2 {
```

## Override the Product Cards in the Carousel

Customize how individual product cards are rendered within the carousel.

<Canvas of={CioRecommendationsStories.OverrideProductCard} />

```jsx
import CioRecommendations from '@constructor-io/constructorio-ui-recommendations';

function App() {
  return (
    <CioRecommendations
      apiKey="YOUR_API_KEY"
      podId="YOUR_POD_ID"
      componentOverrides={{
        carousel: {
          productCard: {
            reactNode: ({ item }) => (
              <div className="custom-product-card">
                <img src={item.imageUrl} alt={item.name} />
                <h3>{item.name}</h3>
                {item.price && <span className="price">${item.price}</span>}
              </div>
            ),
          },
        },
      }}
    />
  );
}
```

### CSS

```css

  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.12);

```
