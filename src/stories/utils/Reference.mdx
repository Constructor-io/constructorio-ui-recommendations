# Utilities

Helper functions for working with Constructor.io recommendation data. These utilities are used internally by the library but can also be imported for custom implementations.

---

## Item Field Getters

Default functions for extracting item data from the API response. Pass custom implementations via the `itemFieldGetters` prop to map your catalog's field names.

### getPrice

Extracts the price from an item or variation.

**Signature:**

```typescript
function getPrice(item: ApiItem | ApiVariation): number | undefined
```

**Parameters:**
- `item` (ApiItem | ApiVariation): The item or variation object from the API response

**Returns:**
- `number | undefined`: The price value from `item.data.price`

**Usage:**

```javascript
import { getPrice } from '@constructor-io/constructorio-ui-recommendations';

const price = getPrice(item);
// Returns: 29.99
```

### getSwatches

Builds an array of swatch items from an item's variations.

**Signature:**

```typescript
function getSwatches(
  item: ApiItem,
  retrievePrice: (item) => number | undefined,
  retrieveSalePrice: (item) => number | undefined,
  retrieveRolloverImage: (item) => string | undefined,
  retrieveSwatchPreview: (variation) => string | undefined
): SwatchItem[] | undefined
```

**Parameters:**
- `item` (ApiItem): The item object containing variations
- `retrievePrice`: Function to extract price
- `retrieveSalePrice`: Function to extract sale price
- `retrieveRolloverImage`: Function to extract rollover image
- `retrieveSwatchPreview`: Function to extract swatch preview

**Returns:**
- `SwatchItem[] | undefined`: Array of swatch items built from variations that have swatch previews

**Usage:**

```javascript
import { getSwatches, getPrice, getSalePrice, getRolloverImage, getSwatchPreview } from '@constructor-io/constructorio-ui-recommendations';

const swatches = getSwatches(item, getPrice, getSalePrice, getRolloverImage, getSwatchPreview);
// Returns: [{ variationId: "var-1", swatchPreview: "...", price: 29.99, ... }, ...]
```

## Response Transformers

Functions for transforming API responses to the library's internal format. These handle snake_case to camelCase conversion and data flattening.

### transformRecommendationResponse

Transforms a raw API response into the library's `RecommendationsData` format.

**When to use:**
- When implementing server-side rendering and need to transform initial data
- When building custom data pipelines with raw API responses

**Signature:**

```typescript
function transformRecommendationResponse(
  res: ApiRecommendationsResponse,
  options?: { itemFieldGetters: Partial<ItemFieldGetters> }
): RecommendationsData | null
```

**Parameters:**
- `res` (ApiRecommendationsResponse): Raw response from the Constructor.io Recommendations API
- `options.itemFieldGetters` (`Partial<ItemFieldGetters>`): Optional custom field getter functions

**Returns:**
- `RecommendationsData | null`: Transformed response with camelCase properties and flattened item data, or null if response is invalid

**Usage:**

```javascript
import { transformRecommendationResponse } from '@constructor-io/constructorio-ui-recommendations';

// Transform raw API response
const transformedData = transformRecommendationResponse(apiResponse);

// With custom field getters
const transformedData = transformRecommendationResponse(apiResponse, {
  itemFieldGetters: {
    getPrice: (item) => item.data.custom_price,
  },
});
```

### transformResultItem

Transforms a single API item into the library's `Item` format.

**Signature:**

```typescript
function transformResultItem(
  resultItem: ApiItem,
  options?: { itemFieldGetters?: Partial<ItemFieldGetters> }
): Item
```

**Parameters:**
- `resultItem` (ApiItem): Raw item from the API response
- `options.itemFieldGetters` (`Partial<ItemFieldGetters>`): Optional custom field getter functions

**Returns:**
- `Item`: Transformed item with flattened data properties

### transformPodData

Transforms pod metadata from API format to library format.

**Parameters:**
- `podData` (ApiPod): Raw pod data from the API response

**Returns:**
