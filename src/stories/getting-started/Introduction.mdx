# Constructor Recommendations UI

[Constructor Recommendations UI](https://github.com/Constructor-io/constructorio-ui-recommendations) is a React library that provides components for fetching and rendering product recommendations powered by Constructor.io. It handles state management, data fetching, and rendering logic out of the box.

## Prerequisites

- React 16.12+
- Constructor.io API key
- Recommendations Pod ID
