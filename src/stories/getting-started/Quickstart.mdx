# Quickstart

Get up and running with Constructor Recommendations UI.

## Step 1: Install

```bash
npm install @constructor-io/constructorio-ui-recommendations
```

## Step 2: Basic Setup

```jsx
import CioRecommendations from '@constructor-io/constructorio-ui-recommendations';
import '@constructor-io/constructorio-ui-recommendations/styles.css';

function App() {
  return (
    <CioRecommendations
      apiKey="YOUR_API_KEY"
      podId="YOUR_POD_ID"
    />
  );
}
```
Replace `YOUR_API_KEY` with your Constructor.io API key and `YOUR_POD_ID` with the pod ID configured in your [Constructor Dashboard](https://internal-app.constructor.io/dashboard/recommendations).

## Step 3: Optional Styling

By default, no styles are included. Import the starter styles to get a baseline look:

```jsx
import '@constructor-io/constructorio-ui-recommendations/styles.css';
```

The starter styles are scoped to `.cio-recommendations` and can be extended or replaced with your own CSS.
