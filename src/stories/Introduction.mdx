# Welcome to Constructor's Recommendations UI

Integration with Constructor's Recommendations API has never been easier with **comprehensive components** that take care of both the tracking and results retrieval,
allowing you to focus on developing your own unique site experience.

If you prefer hooks, we provide the **useRecommendationResults** hook that accepts a suite of configuration parameters and returns all the underlying logic that powers all our components.
